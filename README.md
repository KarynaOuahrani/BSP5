# BSP5(Bachelor Semester Project 5)

The project, titled “Eco Monitoring:
Pollution Discovery and Monitoring,” objectives to analyze and
visualize pollution trends across six European Union countries:
Germany, France, Italy, Spain, Poland, and Luxembourg. By
focusing on three major pollution categories—air, water, and
industrial emissions, this project provides valuable understanding into environmental trends.
The study concentrates on three critical air pollutants:
NO2, O3, and PM2.5, which have significant implications for
public health. By analyzing pollution data from 2014 to 2021
sourced from the European Environment Agency (EEA).
A web-based platform is developed to contibute user interaction with the data. It features a SQL-based relational
database for efficient data storage and management, a frontend interface designed with HTML, CSS, and JavaScript, and
dynamic data visualizations powered by Chart.js. The platform
enables users to explore pollution trends through interactive
graphs and provides researchers, and other people with accessible understanding into the effectiveness of environmental
regulations.
The findings underscore the importance of data-driven
decisions in reducing pollution’s on public health and ecosystems. By making this data accessible, the project contributes to
constant efforts to improve environmental quality and promote
sustainable development across the EU.
Keywords: NO2, O3, PM2.5, air pollutant



## How to Run the Application

Make sure Python 3.8 or newer is installed on your system. Clone the repository and navigate into the project directory. (Optional) Create and activate a virtual environment using `python -m venv venv`, then activate it with `venv\Scripts\activate` on Windows or `source venv/bin/activate` on macOS/Linux. Install Flask using `pip install flask`. Run the application with `python Flask.py` (or `python3 Flask.py`). Once the server starts, open your browser and go to `http://...` to view the application.

## Notes

Flask automatically searches for HTML templates inside the `templates` directory. The file name `Flask.py` is valid but not standard practice; in larger projects it is usually renamed to `app.py`. This project is intended as a basic learning example of Flask.
